# jobstar

Boss 直聘岗位匹配与沟通助手。采集岗位 → 硬门禁过滤 → 按能力卡片打分 →
生成开场白 → **人工在本地面板逐条确认** → 执行器发送 → 台账留痕。

绝不自动发送。所有对外发出的消息都必须经过面板上的一次人工点击，这是
结构性保证，不是配置项。

## 启动

```bash
uv run jobstar serve            # 本地面板 http://127.0.0.1:8777
```

面板里就能完成日常全部操作：

| 页面 | 干什么 |
| --- | --- |
| **待确认队列** | 逐条过目招呼话术，改完再确认。发出去的就是框里那段文字 |
| **采集与打分** | 拉列表 → 勾选要抓哪些 → 抓详情 → 打分。跑的过程有实时日志，随时能停 |
| **能力卡片** | 直接编辑 `data/capability_cards.yaml`，每次保存前自动备份 |
| **标注** | 快速判断「会投／不会投」，键盘 y / n 翻页 |
| **阈值** | 用标注反推入队阈值，而不是拍脑袋定一个数 |
| **设置** | 门禁规则、维度权重、每日上限 |

采集会驱动你本机那个 Chrome（通过 browser-harness 复用已有登录态），所以
**浏览器要开着并且已经登录 Boss**。同一时刻只允许一个任务在跑。

### 采集是两步，不是一把梭

1. **拉取列表** —— 只翻列表页，一个详情页都不打开。拉完下面出现候选列表。
2. **勾选要抓的** —— 全选、或者只挑几个，然后「抓选中的详情页」。

详情页请求是整条链路上唯一一个「按岗位数量线性增长、真正打在 Boss 上」的
动作，也是最该由人决定量的地方。被预门禁刷掉的岗位照样列出来（灰显、默认
不勾、标着原因），手动勾上就会覆盖门禁 —— 人的判断压过规则。

候选列表里薪资一栏基本是空的（`-K·薪`）：Boss 列表页用反爬字体把数字抠掉了，
真实薪资要抓了详情页才有。

运行中的任务可以随时**停止**。停止是协作式的：当前这个岗位跑完才会停下
（LLM 调用和页面抓取都没法中途掐断）。已经处理完的都已入库，没轮到的下次
再跑还会被捡起来，不需要 `--rescore`。

### 发送（只有这一步在命令行）

```bash
uv run jobstar send             # 只发送你已经在面板上确认过的动作
```

没做成面板按钮是有意的：发送要逐条打开页面、按人类节奏间隔几分钟，
放进 HTTP 请求里只会超时。

### 其余命令行入口

```bash
uv run jobstar init                                  # 建库
uv run jobstar collect --keyword "后端开发" --pages 3  # 等价于面板的采集
uv run jobstar score [--rescore] [--job-id ID]       # 等价于面板的打分
uv run jobstar cards                                 # 校验卡片库，看证据强度分布
```

`--rescore` 把四种「吸收态」放回队列重新处理：打分失败、话术生成失败、
被第二遍门禁刷掉、以及已经打过分的岗位（改完权重或 prompt 要对照标注
校准时用它）。面板上对应「采集与打分」页的**重跑吸收态**勾选项。

## 冷启动

`score_threshold` 默认是 `null` —— 这时一条待确认动作都不会生成。先在
「标注」页攒 30-50 条，再去「阈值」页看两组分数的分布，反推出一个阈值填进
设置里。填之前系统发不出任何消息。

## 能力卡片

`data/capability_cards.yaml` 是打分的唯一依据。格式见
[docs/capability_cards.example.yaml](docs/capability_cards.example.yaml)。

「证据强度」只能是 强 / 中 / 弱：**强 = 能讲 30 分钟，中 = 能讲 5 分钟，
弱 = 仅接触**。这一列是整套系统防止简历吹牛的唯一防线，必须逐张校对，
宁可低估 —— 标高了，出来的分数和话术都会虚。面板在「强」的占比超过 60%
时会提醒你。

`data/` 整个目录不入 git：里面是真实雇主、项目代号、客户案例，以及本人
对每项能力的诚实自评。面板每次保存卡片前会在 `data/card-backups/` 留一份
带时间戳的备份 —— 这份文件没有版本历史兜底。

## 配置

复制 `.env.example` 为 `.env`：

```
JOBSTAR_LLM_BACKEND=claude_cli   # 调本机 claude CLI，复用 Claude Code 登录态
# 或 gateway，走 OpenAI 兼容网关，需要填 BASE_URL / API_KEY
```

## 开发

```bash
uv run pytest -q
```

面板前端是单个 `src/jobstar/panel/static/index.html`，无构建、无外部依赖。
`tests/test_panel_html.py` 盯着它的两条不变量：每个插值都必须经过
`esc()`／`safeHref()`，以及那段内联 JS 必须能通过语法检查（装了 node 时
才跑真实校验）。
